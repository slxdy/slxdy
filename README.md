# Hi, I'm Michal

## MelonLoader

I contributed to [MelonLoader](https://github.com/LavaGang/MelonLoader), a mod loader for Unity games (Mono and IL2CPP) with 4k+ ★.

- **Bootstrap rewrite:** rewrote the native bootstrap from Rust to C# compiled with NativeAOT
- **Simpler configuration:** moved loader settings from command-line arguments into a plain config file
- **[MelonLoader.Installer](https://github.com/LavaGang/MelonLoader.Installer):** rewrote the official installer from scratch, moving it from WinForms to Avalonia and adding automatic game detection
- **[MelonLoader.UnityDependencies](https://github.com/LavaGang/MelonLoader.UnityDependencies):** built a GitHub Actions pipeline that collects Unity runtime libraries for MelonLoader's assembly generation
